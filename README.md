# Hipster Burger Ecommerce — SMASHED

Frontend interactivo y en 3D para un e-commerce de smash burgers con estética indie/urbana. Construido con Next.js (App Router), Three.js (React Three Fiber), Framer Motion y Tailwind CSS, optimizado para consumo de APIs REST.

## Stack

- Next.js 16 (App Router, TypeScript)
- Tailwind CSS v4
- Zustand (carrito, persistido en localStorage)
- Framer Motion
- React Three Fiber + drei + three.js (hero 3D)
- Radix UI (accesibilidad en drawer/menú)

## Desarrollo

```bash
npm install
npm run dev
```

Abrí [http://localhost:3000](http://localhost:3000).
